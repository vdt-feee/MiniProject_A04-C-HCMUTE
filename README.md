Đề tài: A04, C09


1. Danh sách các file mã nguồn:
•	tiendien.h (File thư viện chung)
•	main.c (Menu chính)
•	chuc_nang_1.c đến chuc_nang_5.c (Các hàm xử lý)
-   chuc_nang_morong1.c và chuc_nang_morong2.c
2. Hướng dẫn biên dịch và chạy (Nếu dùng Visual Studio Code):

•	Bước 1: Mở Terminal tại thư mục chứa code.
•	Bước 2: Gõ lệnh sau để biên dịch (gom các file lại): gcc main.c chuc_nang_1.c chuc_nang_2.c chuc_nang_3.c chuc_nang_4.c chuc_nang_5.c -o tiendien
•	Bước 3: Gõ lệnh sau để chạy chương trình: ./tiendien (trên Mac/Linux) hoặc .\tiendien.exe (trên Windows)

3. Hướng dẫn biên dịch và chạy (Nếu dùng Dev-C++ / Code::Blocks):
•	Bước 1: Tạo một Project mới (File -> New -> Project -> Console Application).
•	Bước 2: Kéo thả toàn bộ các file .c và .h vào chung Project này.
•	Bước 3: Bấm phím F11 (Compile & Run) để chạy.
